# Shooter MF

Редактор скриншотов для macOS и Windows. Захват области экрана, рисование и выделение маркером, фигуры, текст, копирование и сохранение PNG.

- [macOS](Kadr/README.md) — исходники на Swift и AppKit, инструкции по сборке и подписи.
- [Windows](Kadr-Windows/README.md) — исходники на C# и Windows Forms, сборка для x64 и ARM64, установщик NSIS.

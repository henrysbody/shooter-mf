# Shooter MF для Windows

## Установка

Запустите `Shooter MF-Windows-Setup.exe` на Windows x64 или ARM64. Установщик выбирает сборку под архитектуру компьютера, добавляет ярлык в меню «Пуск» и регистрирует Shooter MF в списке установленных приложений текущего пользователя.

На последнем экране можно включить запуск при входе в Windows и запуск сразу после установки. При первой установке обе галочки отмечены. При повторной установке учитывается сохранённый выбор автозапуска.

Для портативного запуска распакуйте архив для своей архитектуры и откройте `Shooter MF.exe`. Сборка x64 подходит для компьютеров с Intel и AMD, сборка ARM64 — для Windows на ARM. Отдельно устанавливать .NET не нужно.

Левый клик по значку Shooter MF в области уведомлений открывает стартовое окно. В нём есть список горячих клавиш и флажок автозапуска. Правый клик открывает меню действий.

- **Alt+Shift+S** открывает редактор. Потяните мышью, чтобы выделить область. Перетаскивайте рамку для перемещения и её углы или стороны для изменения размера.
- **F** переключает полный экран и предыдущую область. Если области ещё не было, появится небольшой прямоугольник по центру экрана. Выбор режима запоминается.
- **T** выбирает текст, **S** выбирает прямоугольник, **R** выбирает овал. **E** выбирает линию, **A** выбирает стрелку, **D** выбирает карандаш, **Q** выбирает маркер. Через секунду после наведения справа от иконки появляется подсказка с горячей клавишей.
- Цифры **1–7** выбирают красный, зелёный, синий, фиолетовый, жёлтый, чёрный и белый соответственно.
- **+** и **−** меняют толщину кисти или размер текста на один шаг. **Tab** перебирает три размера по кругу, **Shift+Tab** идёт в обратном порядке. Эти клавиши работают вне набора текста.
- Удерживайте **Shift**, чтобы выделить квадрат, нарисовать квадрат или круг, либо провести линию или стрелку с шагом 45°.
- Панель появляется после начала выделения и следует за ним под нижней центральной ручкой. Если снизу мало места, она поднимается выше. В меню есть карандаш, маркер, прямоугольник, овал, стрелка, линия и текст. Линию и стрелку рисуют перетаскиванием между двумя точками.
- Карандаш сглаживает движение мыши. Чтобы перетащить штрих целиком, потяните за саму линию. У штриха меловая фактура, мягкая тень вниз и вправо и более широкий мазок вдоль диагонали ↗.
- У фигур ровные контуры с лёгкой меловой фактурой и мягкой тенью вниз и вправо. У стрелки острый наконечник с короткими крыльями, загнутыми наружу. Основание стрелки и начало линии шире. У линии и штриха карандаша следы сухой щетины видны с обоих концов, у стрелки — у основания. Рисунок щетины выбирается отдельно для каждого конца и сохраняется при перемещении и редактировании. Контуры овала и прямоугольника немного толще слева вверху и справа внизу.
- Текст набирается поверх снимка шрифтом на основе **Geologica Medium** с кириллицей. Цвет совпадает с цветом фигур в палитре. **Enter** фиксирует надпись и завершает ввод. **Shift+Enter** начинает новую строку. У букв мягкая фоновая тень по всему контуру и такая же тень вниз и вправо, как у фигур. У текста **16 pt** стандартный межбуквенный интервал Geologica. Размер по умолчанию — **24 pt**.
- Потяните за контур фигуры или линию, чтобы её переместить. Потяните за синюю ручку, чтобы изменить размер или передвинуть один конец линии или стрелки. Перетащите надпись, чтобы переместить её, или щёлкните дважды, чтобы изменить текст.
- **Ctrl+C** копирует снимок и закрывает редактор. Уведомление появляется внизу.
- **Ctrl+S** открывает «Сохранить как…» в папке «Загрузки». После сохранения PNG снимок копируется в буфер, а редактор закрывается.
- **Delete** или **Backspace** удаляет выделенную пометку. Если ничего не выделено, клавиша удаляет все пометки. Под панелью инструментов на три секунды появляется плашка «Отменить». Нажатие в любом месте плашки возвращает удалённые пометки. **Ctrl+Z** отменяет последнее изменение, **Ctrl+Shift+Z** повторяет его. **Esc** сначала отменяет текущий ввод текста, рисунок или изменение области. Следующее нажатие закрывает редактор.

Сборки выпущены без подписи Authenticode. Собраны для x64 и ARM64. Работа интерфейса на Windows не проверялась.

Для сборки из исходников с .NET 10 SDK:

```powershell
dotnet publish Kadr.csproj -c Release -r win-x64 --self-contained true
dotnet publish Kadr.csproj -c Release -r win-arm64 --self-contained true
```

Установщик собирается из `Installer/Kadr.nsi` с помощью NSIS 3.12 или новее. Передайте версию приложения, абсолютные пути к обеим сборкам, папке `Licenses` из портативного архива и выходному файлу.

```powershell
makensis /INPUTCHARSET UTF8 /DAPP_VERSION=1.0.56 `
  "/DX64_EXE=C:\Kadr\x64\Shooter MF.exe" "/DARM64_EXE=C:\Kadr\arm64\Shooter MF.exe" `
  "/DLICENSE_DIR=C:\Kadr\Licenses" "/DSETUP_EXE=C:\Kadr\Shooter MF-Windows-Setup.exe" `
  Installer\Kadr.nsi
```

# Shooter MF

Нативное приложение для macOS 14 и новее: выделение области экрана, быстрые пометки и копирование готового скриншота в буфер обмена.

Готовый архив `Shooter MF-macOS.zip` содержит универсальную сборку для Apple Silicon и Intel.

## Запуск

1. Распакуйте `Shooter MF-macOS.zip` и перенесите `Shooter MF.app` в папку «Программы».
2. Откройте приложение. Его значок появится в строке меню.
3. При первом снимке разрешите запись экрана в «Системные настройки → Конфиденциальность и безопасность → Запись экрана». Если macOS попросит, завершите и снова откройте приложение.

Для этого Mac используется постоянный локальный сертификат подписи. Для публичного распространения нужны Developer ID и нотариализация Apple. Если macOS блокирует запуск, разрешите открытие знакомого приложения в «Системные настройки → Конфиденциальность и безопасность».

При переходе с прежней ad hoc сборки на постоянный сертификат может понадобиться один раз обновить разрешение записи экрана. Если переключатель включён, а новая версия не получает доступ, удалите Shooter MF из списка записи экрана кнопкой «−» и добавьте установленное приложение заново кнопкой «+». Затем перезапустите приложение. Последующие сборки используют тот же сертификат и идентификатор приложения.

## Работа со скриншотом

- **⌘⇧S** — начать выделение. Потяните мышью, чтобы задать область.
- Перетаскивайте рамку, чтобы переместить область. Тяните за углы и середины сторон, чтобы изменить размер. Для нового выделения потяните мышью вне рамки.
- Панель появляется после начала выделения и следует за ним под нижней центральной ручкой. Если снизу мало места, она поднимается выше. Нажмите значок инструмента, цветную точку или образец линии, чтобы открыть соответствующее меню.
- Чтобы нарисовать стрелку, выберите её в меню или нажмите **A**. Нажмите в начальной точке, потяните к цели и отпустите. Наконечник окажется в точке отпускания.
- **F** переключает полный экран и предыдущую область. Если области ещё не было, появится небольшой прямоугольник по центру экрана. Выбор режима запоминается.
- **T** выбирает текст, **S** выбирает прямоугольник, **R** выбирает овал. **E** выбирает линию, **A** выбирает стрелку, **D** выбирает карандаш, **Q** выбирает маркер. Через секунду после наведения справа от иконки появляется подсказка с горячей клавишей.
- Цифры **1–7** выбирают красный, зелёный, синий, фиолетовый, жёлтый, чёрный и белый соответственно.
- **+** и **−** меняют толщину кисти или размер текста на один шаг. **Tab** перебирает три размера по кругу, **Shift+Tab** идёт в обратном порядке. Эти клавиши работают вне набора текста.
- Удерживайте **Shift**, чтобы выделить квадрат, нарисовать квадрат или круг, либо провести линию или стрелку с шагом 45°.
- Линию можно перемещать целиком или двигать любой её конец.
- Карандаш сглаживает движение мыши. Чтобы перетащить штрих целиком, потяните за саму линию. У штриха меловая фактура, мягкая тень вниз и вправо и более широкий мазок вдоль диагонали ↗.
- У фигур ровные контуры с лёгкой меловой фактурой и мягкой тенью вниз и вправо. У стрелки острый наконечник с короткими крыльями, загнутыми наружу. Основание стрелки и начало линии шире. У линии и штриха карандаша следы сухой щетины видны с обоих концов, у стрелки — у основания. Рисунок щетины выбирается отдельно для каждого конца и сохраняется при перемещении и редактировании. Контуры овала и прямоугольника немного толще слева вверху и справа внизу.
- При первом запуске выбран красный прямоугольник. Инструмент, цвет, толщина линий и размер текста запоминаются независимо между снимками и перезапусками.
- Толщина линий — **2, 4 или 8 pt**. В режиме текста это меню выбирает размер **16, 24 или 36 pt**. Меню плавно раскрывается прямо над своей кнопкой.
- Текст вводится поверх снимка шрифтом на основе **Geologica Medium** с кириллицей. Цвет совпадает с цветом фигур в палитре. У букв мягкая фоновая тень по всему контуру и размытая тень вниз и вправо. **Enter** фиксирует надпись и завершает ввод. **Shift+Enter** начинает новую строку. Щелчок за пределами текста также фиксирует надпись. У текста **16 pt** стандартный межбуквенный интервал Geologica. Размер по умолчанию — **24 pt**.
- Потяните за контур прямоугольника или овала либо за линию стрелки, чтобы переместить фигуру. Потяните за синюю угловую ручку или конец стрелки, чтобы изменить размер. Перетащите надпись, чтобы переместить её, или щёлкните дважды, чтобы изменить текст.
- **Delete** или **Backspace** удаляет выделенную пометку. Если ничего не выделено, клавиша удаляет все пометки. Под панелью инструментов на три секунды появляется плашка «Отменить». Нажатие в любом месте плашки возвращает удалённые пометки. **⌘Z** отменяет последнее изменение, **⇧⌘Z** повторяет его.
- **⌘C** — скопировать готовое изображение и закрыть редактор. Короткое уведомление внизу экрана подтверждает копирование.
- **⌘S** открывает «Сохранить как…». По умолчанию выбрана папка «Загрузки», формат — PNG. После сохранения снимок также копируется в буфер обмена, а редактор закрывается.
- **Esc** отменяет текущий ввод текста, рисунок или изменение области, пока действие продолжается. Следующее нажатие закрывает редактор без копирования.

Приложение остаётся в строке меню после закрытия редактора. Завершить его можно через меню значка. Автоматический запуск при входе не включается.

## Сборка из исходников

Нужны macOS 14+ и Command Line Tools для Xcode (установка: `xcode-select --install`). Сторонних зависимостей нет.

Сначала настройте существующий сертификат Code Signing из связки ключей. Вместо `SHA1` подставьте его 40-значный отпечаток:

```sh
./configure-signing.sh SHA1
```

Настройка этого Mac хранится в приватном файле `~/Library/Application Support/Kadr/signing-identity`. В нём находится только SHA1; сертификат и закрытый ключ остаются в связке ключей. Обычная сборка требует доступный настроенный сертификат и автоматически использует его:

```sh
./build.sh
```

Приложение `Shooter MF.app` и архив `Shooter MF-macOS.zip` появятся рядом с папкой исходников. По умолчанию используется архитектура текущего Mac.

Для универсальной сборки Apple Silicon + Intel:

```sh
./build.sh --universal
```

Переменная окружения `KADR_SIGN_IDENTITY` позволяет явно выбрать SHA1 другого доступного сертификата для одной сборки. Скрипты и исходники не содержат закрытого ключа или экспортированной identity.

Для одноразовой разработки доступен явный режим:

```sh
./build.sh --universal --adhoc
```

Ad hoc подпись привязана к конкретной сборке, поэтому после обновления разрешение записи экрана может потребоваться выдать заново.

Проверка постоянной подписи:

```sh
./verify-signing.sh
```

Команда работает с двумя временными копиями приложения: подтверждает разные хэши кода (CDHash), общую привязанную к сертификату идентичность (DR) и взаимное прохождение проверки требований подписи. Это проверяет, что новая сборка распознаётся как обновление той же программы.

Для запуска используйте собранный `.app`: идентификатор пакета нужен macOS для разрешения записи экрана. Исходники также содержат `Package.swift` для открытия проекта в редакторе.

Проверки редактора запускаются командой `./test.sh`: обрезка и исходное разрешение, инструменты рисования, текст, история изменений и изменение границ выделения. Вариант `./test.sh --window` также ненадолго открывает окно для проверки отрисовки и курсора. Команда `./make-icon.sh` заново создаёт иконку из векторного описания на Swift.
